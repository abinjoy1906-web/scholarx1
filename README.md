# 📄 Document Classifier

A complete, end-to-end machine learning project for multi-class text / document
classification, built with **Python**, **Scikit-learn**, **NLTK**, and **Streamlit**.

---

## 🌟 Features

| Feature | Details |
|---|---|
| **Dataset** | 20 Newsgroups – 8 curated categories, ~4 500 documents |
| **Preprocessing** | Lower-casing · Punctuation removal · Stopword removal · Lemmatization |
| **Feature Engineering** | TF-IDF Vectorizer (15k vocab, bigrams, sublinear TF) |
| **Model** | Multinomial Naive Bayes (α = 0.1) |
| **Evaluation** | Accuracy · Confusion matrix · Classification report |
| **Persistence** | Model + vectorizer saved as `.pkl` files |
| **CLI Predictor** | `python src/predict.py "<text>"` |
| **Web App** | Streamlit UI with confidence bars and category sidebar |

## 🗂️ Dataset

The project uses the **[20 Newsgroups](https://scikit-learn.org/stable/datasets/real_world.html#the-20-newsgroups-text-dataset)**
dataset, an industry-standard benchmark for text classification.

An 8-category subset is used for faster iteration:

| Short Label | Newsgroup ID | Description |
|---|---|---|
| Hockey | `rec.sport.hockey` | Ice hockey discussion |
| Baseball | `rec.sport.baseball` | Baseball discussion |
| Medicine | `sci.med` | Medical science topics |
| Space | `sci.space` | Space exploration & astronomy |
| Politics | `talk.politics.guns` | Gun-control political debate |
| Religion | `talk.religion.misc` | General religious discussion |
| Computing | `comp.graphics` | Computer graphics & rendering |
| Christianity | `soc.religion.christian` | Christian theology & practice |

> Headers, footers, and quoted reply blocks are stripped to prevent leakage.

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/your-username/document-classifier.git
cd document-classifier
```

### 2. Create a virtual environment (recommended)

```bash
python -m venv venv
# macOS / Linux
source venv/bin/activate
# Windows
venv\Scripts\activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

NLTK corpora are downloaded automatically on first run.

---

## 🚀 Usage

### Train the model

```bash
python src/train.py
```

This will:
- Download the 20 Newsgroups dataset  
- Preprocess all documents  
- Fit the TF-IDF vectorizer and Naive Bayes classifier  
- Print accuracy + classification report  
- Save a confusion-matrix plot to `screenshots/`  
- Persist model artefacts to `models/`

### Predict via CLI

```bash
# Pass text as argument
python src/predict.py "NASA scientists found evidence of ancient water on Mars."

# Or run interactively
python src/predict.py
```

### Launch the Streamlit app

```bash
streamlit run app.py
```

Then open **http://localhost:8501** in your browser.
